# Vizuara AI Engineering Workshops

Four instructor-led 15–20 minute demonstrations aligned with LedgerGate's research packages.

1. [Transformers from first principles](01-transformers-from-first-principles.md)
2. [Building and evaluating AI agents](02-building-and-evaluating-agents.md)
3. [PPO and GRPO](03-ppo-and-grpo.md)
4. [LLM inference and GPU performance](04-inference-and-gpu-performance.md)

Each lesson includes objectives, prerequisites, a timed teaching plan, coding demonstration, mathematical or architectural explanation, common mistakes, applications, interview questions, and a student exercise.

Instructor rules: run the package tests before presenting; use CPU-compatible settings; show real outputs from the actual run; label unavailable metrics as unavailable; never present illustrative values as measurements. The research packages are educational and must not bypass LedgerGate's financial authorization or human approval boundary.
